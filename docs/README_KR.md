## 개발 분야

실제 환경을 측정하고, 장치에서 판단한 뒤 필요한 순간에 경보를 전달하는 임베디드 시스템을 개발합니다. 현재 포트폴리오는 수질, 정전, 산불 위험 모니터링과 개발 도구를 포함합니다.

## 주요 프로젝트

| 프로젝트 | 기능 | 핵심 기술 |
| --- | --- | --- |
| [Water Quality Monitor](https://github.com/achmad-miftahurrojak/water-quality-monitor) | TDS, pH, 탁도를 측정하고 결과를 저장합니다. | ESP32 · C++ · PlatformIO |
| [Power Outage Predictor](https://github.com/achmad-miftahurrojak/power-outage-predictor) | AC 전압 상태를 분류하고 정전 시 SMS를 보냅니다. | ESP32 · C++ · ZMPT101B · GSM |
| [Forest Fire Early Warning](https://github.com/achmad-miftahurrojak/forest-fire-early-warning) | LoRa 센서 노드의 환경 데이터를 경보 허브로 전송합니다. | ESP32 · C++ · LoRa · SIM800L |

각 하드웨어 저장소에는 아키텍처 문서, 펌웨어 구조, 빌드 명령, 로컬 secret 설정 경계가 포함되어 있습니다.

## 하드웨어 스택
