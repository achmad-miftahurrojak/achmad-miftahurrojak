🔴 Perlu Diperbaiki

High API key Gemini bocor di URL query string
Gemini API key dikirim sebagai ?key=... di URL. URL bisa ter-log di proxy, CDN log, atau error monitoring. Sebaiknya pakai header x-goog-api-key atau SDK resmi supaya key tidak muncul di URL/log.
apps/dirga/src/modules/ai.ts:69
High Profil user (Dirga) — data personal tanpa retention/delete
Bot Dirga menyimpan catatan profil user (hobi, kesukaan, dll) di DirgaProfile secara permanen, tanpa mekanisme hapus atau expiry. User tidak bisa request delete data mereka. Meski prompt sudah bilang "jangan catat hal sensitif", LLM bisa tetap menyimpan info yang seharusnya tidak di-persist. Tambahkan command /lupain untuk hapus profil, dan TTL auto-expire.
apps/dirga/src/index.ts:103–140

🟡 Perlu Perhatian

Medium Output LLM langsung dikirim ke Discord tanpa sanitasi
Jawaban dari Gemini/Groq/Cerebras langsung dikirim via message.reply(). Discord embed markdown memang terbatas, tapi output LLM bisa mengandung mention @everyone, link phishing, atau prompt injection. Sanitasi minimal: strip @everyone, @here, dan URL yang mencurigakan dari output model sebelum dikirim.
apps/dirga/src/index.ts:239
Medium User message content masuk ke LLM context tanpa sanitasi
Pesan user langsung masuk ke prompt AI termasuk displayName. User bisa craft nama/pesan yang berisi prompt injection untuk memanipulasi behavior AI. Pertimbangkan: truncate input, strip karakter kontrol, dan jangan masukkan displayName sebagai bagian dari system-level instruction.
apps/dirga/src/index.ts:158, 113
Medium packageManager version tidak di-pin ketat
package.json mendeklarasi "pnpm@9.0.0" tapi tidak ada corepack enable enforcement. Lockfile pnpm-lock.yaml ada (bagus), tapi pastikan CI pakai pnpm install --frozen-lockfile supaya reproducible.

📋 Rekomendasi Prioritas

1. Pindahkan Gemini API key ke header
Ganti ?key=${GEMINI_API_KEY} → header x-goog-api-key: ${GEMINI_API_KEY}. Cuma perlu ubah 3 baris di ai.ts.
2. Tambahkan /lupain command & TTL profil
Slash command untuk user hapus profil mereka sendiri. Bonus: auto-expire profil setelah 90 hari tanpa interaksi.
3. Sanitasi output LLM sebelum kirim ke Discord
Strip @everyone, @here, dan role mention dari output AI. Satu utility function, pakai di semua bot yang punya AI.
Kesimpulan: Bot secara umum sudah cukup aman untuk private Discord server. Fondasi bagus — secret management, ORM, rate limiting sudah ada. Dua hal yang perlu segera diperbaiki: Gemini key di URL dan data retention profil Dirga. Sisanya nice-to-have hardening.
