## Yang saya bangun

Saya mengembangkan sistem embedded yang mengukur kondisi nyata, mengambil keputusan lokal, lalu mengirim peringatan saat dibutuhkan. Portofolio ini mencakup kualitas air, gangguan listrik, risiko kebakaran hutan, dan perangkat pengembang.

## Proyek pilihan

| Proyek | Fungsi | Teknologi utama |
| --- | --- | --- |
| [Water Quality Monitor](https://github.com/achmad-miftahurrojak/water-quality-monitor) | Mengukur TDS, pH, dan kekeruhan lalu menyimpan hasilnya. | ESP32 · C++ · PlatformIO |
| [Power Outage Predictor](https://github.com/achmad-miftahurrojak/power-outage-predictor) | Mengklasifikasikan kondisi tegangan AC dan mengirim SMS saat listrik padam. | ESP32 · C++ · ZMPT101B · GSM |
| [Forest Fire Early Warning](https://github.com/achmad-miftahurrojak/forest-fire-early-warning) | Mengirim data lingkungan dari node LoRa ke hub peringatan. | ESP32 · C++ · LoRa · SIM800L |

Setiap repo hardware berisi catatan arsitektur, struktur firmware, perintah build, dan batas konfigurasi untuk secret lokal.
